# BrainForge

BrainForge is an educational web app foundation for kid-friendly learning activities.

## Run

Open `index.html` directly in your browser.

## Tech

- Vanilla HTML, CSS, and JavaScript
- Modular ES modules
- Fully static (no build tools, npm, or frameworks)

## Included Features

- Light/dark theme system with CSS custom properties
- Theme toggle with persistence (`localStorage`) and system preference fallback
- Simple client-side router with placeholder activity routes
- Expandable feature-based activity structure
- Supabase leaderboard smoke-test page (`leaderboard-test.html`) for manual test score inserts and readback

## Future Directions

- Full activity gameplay logic
- Progress tracking and rewards
- More themes and personalization options
- User profiles and avatars
